# 米家桌面端 UI 设计规范（AI 执行版）

> 目标：让 AI 按统一规范设计一套现代化、轻量、克制、具有米家智能家居气质的桌面端应用。
>
> 适用范围：桌面端 Web / Electron / Windows / macOS 风格应用。
>
> 推荐设计基准：1920 × 1080。
>
> 核心关键词：**轻盈、温和、智能、整洁、留白、卡片化、低对比、生活化、现代感。**

---

# 1. 产品定位

产品名称：**米家桌面端**

产品定位：

- 家庭智能设备统一管理平台
- 面向大屏桌面环境，而不是简单放大移动端
- 强调“一屏掌握整个家庭状态”
- 高频操作尽量在首页完成
- 设备、场景、自动化、摄像头、能耗、安全、家庭成员统一管理
- UI 需要兼顾「智能家居科技感」和「家庭生活温度」

设计原则：

1. 信息密度适中，不做传统后台管理系统风格
2. 不使用大量表格
3. 不使用重边框
4. 不使用大面积高饱和颜色
5. 优先使用卡片、状态块、设备图、趋势图、快捷控制
6. 交互状态必须清晰，但视觉表达要克制
7. 页面整体应更接近 Apple Home / Mi Home / Linear / Arc / macOS 的现代产品感

---

# 2. 整体视觉方向

## 2.1 视觉风格

整体采用：

- 浅色主题
- 白色 / 极浅灰背景
- 米家青绿色作为品牌主色
- 低饱和蓝、橙、紫作为功能辅助色
- 大圆角
- 柔和阴影
- 极弱边框
- 大量留白
- 轻量图标
- 真实家居图片作为局部视觉增强

禁止：

- 传统后台管理系统的深色侧边栏
- 蓝色 Ant Design 默认风格
- 大面积纯黑
- 重描边卡片
- 复杂渐变
- 玻璃拟态过度使用
- 赛博朋克、霓虹灯、工业大屏风格
- 过多阴影
- 过度圆润导致“儿童化”

# 4. 色彩系统

## 4.1 品牌主色

```css
--primary: #00c9a7;
--primary-hover: #00b99a;
--primary-active: #00a98c;
--primary-light: #e9fbf7;
```

用途：

- 主按钮
- 开启状态
- 激活菜单
- 设备在线状态
- 高亮数据
- 图表主线

---

## 4.2 中性色

```css
--text-primary: #111111;
--text-secondary: #666666;
--text-tertiary: #999999;
--text-disabled: #b8b8b8;

--bg-page: #f5f7f8;
--bg-card: #ffffff;
--bg-soft: #f8fafa;
--bg-hover: #f3f6f6;

--border: #edeff0;
--divider: #f0f1f2;
```

原则：

- 主文案不要纯黑铺满
- 辅助信息降低对比度
- 卡片之间更多依赖背景层级，而不是边框

---

## 4.3 功能辅助色

```css
--success: #19b893;
--info: #4c9cff;
--warning: #f3a53a;
--danger: #ff5b5b;
--purple: #7a6cf6;
```

推荐：

- 蓝色：摄像头 / 网络 / 水
- 橙色：灯光 / 温度 / 能耗
- 紫色：睡眠 / 场景
- 红色：报警
- 绿色：正常 / 在线 / 安全

# 5. 字体规范

优先：

```text

SF Pro Display
system-ui
```

字号：

```text
页面主标题：28 ~ 32px / 600
模块标题：18 ~ 20px / 600
卡片标题：15 ~ 16px / 600
正文：14 ~ 16px / 400
辅助文字：12 ~ 13px / 400

```

原则：

- 不使用过粗字体
- 大数字允许更突出
- 单位字号比数值小 30% 左右

# 31. AI 生成页面时必须遵守

AI 每生成一个页面，必须满足：

1. 严格使用本规范的颜色
2. 严格使用统一圆角
3. 页面背景统一
4. Sidebar 不随页面变化
5. 页面组件风格统一
6. 不自行引入新的主色
7. 不生成传统后台表格风格
8. 尽量使用 Card + Grid
9. 内容必须真实合理
10. 所有页面支持 1920×1080
11. 同时考虑 1366×768
12. 不允许 UI 元素过大
13. 保证桌面端信息密度
14. 页面应该像成熟商业产品，不像 Demo
